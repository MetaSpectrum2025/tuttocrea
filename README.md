# Tuttocrea

Sito di validazione per Tuttocrea: un unico bot IA che, da un solo argomento, prepara il pacchetto pronto da pubblicare (idea, script, SEO, thumbnail, voce, video, sottotitoli e calendario).

Prodotto di Cosmin Marian Balint (Italia). I pagamenti non sono attivi: il modulo chiede solo la prova di 14 giorni o l’accesso anticipato.

- Landing: `index.html`
- Demo simulata: `demo/index.html`
- Piano interno (costi, limiti, prossimi passi): `plan.md`
